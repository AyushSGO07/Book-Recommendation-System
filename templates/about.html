Recommendation Pipeline

1. Data Processing

The raw dataset consists of implicit and explicit ratings. We apply thresholds to filter out noisy data, requiring a minimum of 200 ratings per user and 50 ratings per book to enter the Collaborative Filtering matrix. This aggressively reduces sparsity and ensures high-quality signal.

2. User-Item Matrix

The filtered data is transformed into a dense pivot table (User-Item Matrix). Rows represent unique books and columns represent users. The cell values are the rating scores. Unrated interactions are handled as zeros.

3. Item-Item Collaborative Filtering

We compute Cosine Similarity across the item vectors in the matrix. When a user requests a recommendation for Book A, the system fetches the precomputed similarity scores and returns the nearest neighbor books (Books B, C, D) in the multi-dimensional space.

4. Model Artifacts

Similarity matrices and popularity rankings are serialized into optimized Pickle objects (pt.pkl, similarity_scores.pkl) allowing for O(1) index lookups and sub-10ms recommendation latency at inference time.
